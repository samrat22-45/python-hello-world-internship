# Python Hello World Project

## Objective
This beginner project checks that Python and the development environment are installed and working.

## Requirements
- Python 3
- Visual Studio Code (recommended)
- Python extension for VS Code (recommended)

## Run the project
1. Open this folder in VS Code.
2. Open `main.py`.
3. Open Terminal → New Terminal.
4. Run:
   ```bash
   python main.py
   ```
   On some Windows installations, use:
   ```bash
   py main.py
   ```
5. Enter your name when prompted.

## Expected example
```text
Enter your name: Samrat
Hello, Samrat! My Python environment is working correctly.
```

## Skills practised
- Running a Python file
- Using `input()` and `print()`
- Defining and calling a function
- Using an `if __name__ == "__main__":` entry point
- Organizing a small project
